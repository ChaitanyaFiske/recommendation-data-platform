
## Run with Docker

### Prerequisites

- Docker Desktop with the Linux container engine running.
- The processed dataset files generated by the project.

### Build the image

```bash
docker compose build
```

### Start the API

```bash
docker compose up
```

The API will be available at:

- Health check: http://localhost:8000/health
- Recommendations: http://localhost:8000/recommendations/1?top_n=10
- Movie details: http://localhost:8000/movies/2959
- Interactive API documentation: http://localhost:8000/docs

### Data requirements

The application expects `ratings.parquet` and `movies.parquet`
inside `data/processed/`. Docker Compose mounts this directory
read-only into the container.

Generate the processed data using the project's data-processing
scripts before starting the API.

### Stop the API

```bash
docker compose down
```
